O **MyDuolingo** é uma plataforma de aprendizagem de idiomas de próxima geração, focada em fornecer uma experiência de utilizador "Elite" e "Absurda". Construído com as tecnologias web mais modernas, combina um design táctil 3D com um sistema multilingue global e inteligência artificial.

---

## ✨ Funcionalidades "Game-Changing"

### 🎨 Design táctil e HD Play
- **Bento UI Grid**: Uma interface organizada, moderna e visualmente impactante.
- **Componentes 3D**: Botões e cartões com profundidade real e sombras dinâmicas.
- **Micro-interações**: Feedback visual imediato e animações fluidas com Framer Motion.

### 🌍 Globalização de Elite (i18n)
- **Suporte Nativo para 6 Idiomas**: Português, Inglês, Espanhol, Francês, Alemão e Italiano.
- **Persistência Inteligente**: O site recorda o teu idioma preferido entre sessões.
- **Portal Legal Internacional**: Termos e Privacidade totalmente localizados.

### 🧠 Aprendizagem Inteligente
- **IA Generativa (Gemini)**: Suporte inteligente e correção de erros em tempo real.
- **Gamificação Extrema**: Sistema de XP, Corações (Vidas) e Ofensivas (Streaks) para manter a motivação.
- **Foco na Ciência**: Baseado em princípios de repetição espaçada e micro-aprendizagem.

---

## 🛠️ Stack Tecnológica

- **Framework**: [Next.js 16 (App Router)](https://nextjs.org/)
- **Core**: React 19 + TypeScript
- **Estilização**: Tailwind CSS 4.0 + Vanilla CSS Custom Tokens
- **Animações**: Framer Motion (Motion/React)
- **Ativos Digitais**: Lottie Animations + Lucide Icons
- **Inteligência Artificial**: Google Gemini API

## 🚀 Começar a Aventura

### Pré-requisitos
- Node.js 20+
- npm / yarn / pnpm

### Instalação

1. Clone o repositório:
```bash
git clone https://github.com/imperador1k/Duolingo-Site.git
```

2. Instale as dependências:
```bash
npm install
```

3. Configure as variáveis de ambiente (Crie um ficheiro `.env`):
```env
GOOGLE_GENAI_API_KEY=tua_chave_aqui
```

4. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no seu navegador para ver a magia acontecer.

## 📁 Estrutura do Projeto

- `/src/app`: Rotas e lógica de páginas do Next.js.
- `/src/components`: Componentes de UI atómicos e reutilizáveis.
- `/src/hooks`: Lógica de estado global e sistema de tradução (i18n).
- `/public`: Ativos estáticos, Lotties e imagens de marca.
