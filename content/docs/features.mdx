# Features

MyDuolingo is packed with features designed to make language learning effective and fun.

## Core Features

### Interactive Lessons

Lessons are structured as bite-sized exercises that adapt to your learning pace. Each lesson includes:

- Multiple choice questions
- Translation exercises
- Listening comprehension
- Speaking practice

### Gamification

Stay motivated with built-in game mechanics:

- **XP Points** — Earn experience for completing lessons
- **Streaks** — Maintain daily learning streaks
- **Leaderboards** — Compete with other learners
- **Achievements** — Unlock badges for milestones

### AI-Powered Learning

Our AI pipeline provides:

- Personalized lesson recommendations
- Conversation practice with AI tutors
- Grammar correction and explanations
- Pronunciation feedback

<Callout type="info" title="Did you know?">
The AI features use Google's Generative AI SDK to provide natural language interactions in over 30 languages.
</Callout>

## Technical Highlights

| Feature | Technology |
|---------|-----------|
| Frontend | Next.js 14, React 18, Tailwind CSS |
| AI | Google GenAI SDK |
| Animations | Lottie, Framer Motion |
| Icons | Lucide React |

## Platform Support

MyDuolingo runs on:

- **Web** — Modern browsers (Chrome, Firefox, Safari, Edge)
- **Mobile** — Responsive design for iOS and Android browsers
- **Desktop** — Windows, macOS, Linux via browser

<Callout type="warning" title="Browser Support">
Internet Explorer is not supported. Please use a modern browser for the best experience.
</Callout>
