# Quick Start

Get the MyDuolingo project running on your local machine in just a few steps.

## Prerequisites

Before you begin, make sure you have:

- **Node.js** 18+ installed
- **npm** or **pnpm** package manager
- **Git** for version control

## Step 1: Clone the Repository

```bash
git clone https://github.com/your-org/myduolingo.git
cd myduolingo
```

## Step 2: Install Dependencies

```bash
npm install
```

This will install all required packages including Next.js, React, Tailwind CSS, and other dependencies.

## Step 3: Set Up Environment Variables

Copy the example environment file:

```bash
cp .env.example .env
```

Fill in the required values, especially your Google AI API key if you want to use AI features.

## Step 4: Run the Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the application.

<Callout type="info" title="Hot Reload">
The development server supports hot module replacement. Changes to your code will be reflected instantly in the browser.
</Callout>

## Step 5: Build for Production

When you are ready to deploy:

```bash
npm run build
npm run start
```
