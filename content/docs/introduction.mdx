# Introduction

Welcome to the **MyDuolingo** developer documentation. This guide covers everything you need to know about the codebase, architecture, and contribution process.

## What is MyDuolingo?

MyDuolingo is an open-source language learning platform inspired by Duolingo. It provides a modern, engaging way to learn languages with features like:

- Interactive lessons with gamification
- AI-powered conversation practice
- Real-time chat with other learners
- Progress tracking and streaks
- Cross-platform support (web, mobile, desktop)

## Who is this documentation for?

This documentation is intended for:

- **Contributors** who want to help build the project
- **Developers** who want to understand the architecture
- **Designers** looking to align with the design system
- **Anyone** curious about how the platform works

<Callout type="info" title="Note">
MyDuolingo is built with Next.js 14, TypeScript, Tailwind CSS, and React 18. Familiarity with these technologies will help you get the most out of this documentation.
</Callout>

## Project Structure

The project follows a standard Next.js App Router structure:

```
src/
├── app/          # Next.js app router pages
├── components/   # Reusable React components
├── hooks/        # Custom React hooks
├── lib/          # Utility functions and configs
└── data/         # Static data and translations
```
